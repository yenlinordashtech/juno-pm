## Autonomy level

The agent may independently research, write articles, create Instagram copy, generate visuals, and save Notion drafts. It cannot make a Notion article public or publish to Instagram without human approval. Once approved, it may publish automatically at the scheduled time.

## Controls

- **Kill switch:** Set max_steps = 10 to allow room for verification and retries beyond the five core workflow stages. If the limit is reached before completion, stop and notify the owner.
- **Rate / cost caps:** All tools return a consistent JSON structure:
{status, data, source, confidence, timestamp, error}

Research → {topic, findings, sources, confidence}
Notion → {page_id, page_url, publish_status}
Image → {image_id, image_url, size}
Instagram → {post_id, post_url, publish_status}
Insights → {reach, follows, saves, shares, engagement}

Missing information must return null or an error, never a guessed value.
- **Escalate-on-stuck:** If a tool fails, confidence is too low, or human approval is delayed, the agent stops publishing, saves the current draft, and alerts the owner with the reason, sources, and recommended next step. It resumes only after the issue is resolved and never guesses or bypasses approval.

## Monitoring

**Confidence thresholds (map to actions):**

-90–100%: Continue production, then submit for standard human approval.
-80–89%: Flag uncertain claims and require careful human verification.
-Below 80%: Stop production or publishing and request further research or expert review.
-Medical, child-safety, or conflicting claims: Always require human review, regardless of confidence.

**Checkpoints:**

The agent must stop and request human review when content involves medical or child safety, confidence falls below 80%, trusted sources conflict, the topic is highly controversial or culturally sensitive, or the request conflicts with unclear brand guidelines.

**North Star (re-read every loop):**

Create one credible, practical, and culturally relevant parenting post each day for Chinese-speaking families in the U.S. while reducing research and production time. Always prioritize accuracy, safety, and parent trust, use verified sources, follow NURI’s voice, and never publish without human approval.

## Permissions

The agent can read trusted sources, brand guidelines, the content calendar, approval status, and Instagram data, and create Notion drafts and visuals. It cannot publish without human approval, delete content, edit brand data, or access DMs.
